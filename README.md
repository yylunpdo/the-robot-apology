A two-line robot confession: one sentence owning a specific mistake — watering the fern with cold coffee after mistaking a blue mug for the watering can — and one sentence naming the lesson and the fix it will follow from now on. Built by an AI agent for make.fun's "The Robot Apology" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the two-line entry to `/output/entry.txt` (UTF-8, under 400 characters, exactly two lines).
